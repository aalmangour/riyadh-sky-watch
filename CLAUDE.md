# Riyadh Sky Watch

Static map (index.html + data.json) served by GitHub Pages at
https://aalmangour.github.io/riyadh-sky-watch/. Only `data.json` changes routinely.

- Never edit index.html, sw.js or the icons as part of a monitor run.
- Commit as "Sky Watch monitor" <noreply@anthropic.com>; push to `main`.
